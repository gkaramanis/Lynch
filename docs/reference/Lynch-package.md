# Lynch: Colour Palettes from David Lynch Films

Colour palettes from David Lynch films, for base graphics and ggplot2.

## Details

- [`lynch_palette()`](https://gkaramanis.github.io/Lynch/reference/lynch_palette.md)
  picks colours from a palette by name.

- [lynch_palettes](https://gkaramanis.github.io/Lynch/reference/lynch_palettes.md),
  [lynch_sequential](https://gkaramanis.github.io/Lynch/reference/lynch_palettes.md)
  and
  [lynch_diverging](https://gkaramanis.github.io/Lynch/reference/lynch_palettes.md)
  hold the discrete palettes, sequential ramps and diverging ramps.

- [`scale_colour_lynch_d()`](https://gkaramanis.github.io/Lynch/reference/scale_colour_lynch_d.md)
  and
  [`scale_colour_lynch_c()`](https://gkaramanis.github.io/Lynch/reference/scale_colour_lynch_d.md),
  with their fill versions, use the palettes in ggplot2.

- [lynch_accessibility](https://gkaramanis.github.io/Lynch/reference/lynch_accessibility.md)
  has colour-blindness test results for every discrete palette.

Start with
[`vignette("Lynch")`](https://gkaramanis.github.io/Lynch/articles/Lynch.md).
